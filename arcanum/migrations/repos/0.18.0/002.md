# Migration 002 (next) — re-seed the local `auto-fix-all` namespace

Copies the content of the legacy `.claude/state/auto-fix-all-config.json`
into `.claude/state/arcanum-config.json`, under the `auto-fix-all`
namespace key — the same operation `0.9.3/001.sh` already performs for
this file.

Why this exists despite `0.9.3/001.sh` already doing this: that migration
is `skippable: true`, and its own description relies on the runtime
`repo_config_read` legacy-file fallback staying a permanent safety net for
repos that skip it. This issue removes that fallback specifically for
`clear_context` and `finish_on_empty_queue` (both stored under this
namespace in this file). This migration is the forcing function that
guarantees every repo — whether or not it ever ran `0.9.3/001.sh` — has
those two values seeded forward into the new namespaced file before the
fallback disappears. That's why this is `skippable: false` where the
original was `true`.

Safe to re-run: if the `auto-fix-all` key already exists in
`.claude/state/arcanum-config.json`, seeding is a no-op — same idempotency
guarantee `0.9.3/001.md` already documents for the same underlying
`repo_config_seed` operation.
