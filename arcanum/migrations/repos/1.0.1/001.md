# Migration 001 (next) — shell engine.mode is deprecated

The `shell` engine (`engine.mode=shell`, today's default when the key is
absent) is deprecated and will be removed in a future arcanum release.
Switch to `native` (requires Node.js) or, once it is implemented,
`docker`. This migration reports your current setting, checks which
tools are available, and offers to write `engine.mode` to your global
arcanum config. If you take no action, arcanum will pick an engine for
you automatically when shell is removed: `native` if Node.js is
available, otherwise `docker` if Docker is available, otherwise a hard
error asking you to install one of them. See
`docs/agents/specs/shell-engine-removal.md` in the arcanum repository
for details.

This prompt is shown once per machine/account, not once per repo.
