# Migration 001 (next) — install the arcanum CLI

Installs or updates the `arcanum-cli` npm package globally, pinned to
the installed arcanum version (`.version` from the install's
`arcanum.json`, or else the exact git tag of a `git clone` install). It
runs the shared client step, `arcanum/_lib/install_cli.sh`, the same one
the installer and the updater use.

Applies once per machine or account (`applies_to: "global"`). `[S]kip`
leaves the client alone and is remembered: the migration is not offered
again. Choosing `[R]un` is the consent, so there is no second `[Y/n]`
prompt and no terminal is needed.

It never downgrades the client and leaves a linked dev checkout
(`npm link`) alone. Any problem (no Node or npm, no network, a version
that can't be resolved) prints a warning naming the manual
`npm i -g arcanum-cli` command, and the migration still succeeds. Setting
`ARCANUM_SKIP_CLI=1` also skips the client step.
