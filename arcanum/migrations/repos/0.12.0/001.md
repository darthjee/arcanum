# Migration 001 (next) — seed plan-issues retry/backoff config

Adds two config keys under the `plan-issues` namespace in
`.claude/state/arcanum-config.json`, used by `arcanum-split-issue`'s
sub-issue push retry loop:

- `max-retry-count` (default `5`)
- `error-sleep-time` (default `5`, seconds)

There is no legacy, pre-namespaced file for these brand-new keys, so this
migration writes them directly via `repo_config_write` with an empty
`<legacy_file>` argument — `repo_config_write`'s seed step is a no-op when
the legacy file doesn't exist.

Safe to re-run: `repo_config_write` always sets the key to the given
value, so re-running this migration simply re-asserts the defaults —
harmless, though it will overwrite a value a user had already customized
by hand. Marked `skippable: true` since `arcanum-split-issue`'s retry
loop already falls back to the same defaults (5 / 5) when the keys are
absent, so skipping this migration doesn't break anything, it just means
the keys stay implicit instead of being written out to the state file.
