# Migration 001 (next) — set the safe-branch config key

Sets `.claude/state/arcanum-config.json`'s `git.safe_branch` key — the
branch (default `origin/main`) that `enhance-issue`, `discuss-issue`,
and `arcanum-split-issue` park the working tree on before/after their
GitHub-only fetch/discuss/split work, so per-issue `issue-<id>` branches
get released promptly in shared-`.git` multi-agent workspaces.

Guesses a default of `<remote>/main` (first `git remote` name, falling
back to `origin` if none is configured) and, when an interactive
terminal is available, offers to confirm the guess, type a different
branch, or skip. Skipping leaves the key unset — `safe_branch.sh`'s own
hardcoded fallback (`origin/main`) still applies at use-time, so
skipping just means "keep the default," not "opt out of the migration."
When no interactive terminal is available (e.g. an automated run), the
guessed default is written silently, no prompt.

Safe to re-run — local, per-clone state (`applies_to: "local"`), so it
re-prompts (or re-applies the default) on every clone/run rather than
being a one-time, repo-wide change.
