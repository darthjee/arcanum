# Migration 002 (next) — set the team-wide default squash-merge body mode

Sets the `git.merge_body_mode` key on the shared, committed
`.claude/configuration/arcanum-repo-config.json`, as the repo-wide
default every contributor falls back to when they haven't set their own
personal value via migration 001 (`.claude/state/arcanum-config.json`
always takes precedence over this file when both are set).

Same three modes as migration 001 — `empty` (today's behavior),
`full` (GitHub/`gh`'s own default squash body), or `coauthors` (a
deduped `Co-authored-by:` block from the PR's commits). See 001.md for
the full explanation of each mode.

**This value gets committed to the repo and is visible to every
contributor** — you'll see an explicit warning to that effect before
being asked to choose. Same interactive shape as migration 001
otherwise: `[E]mpty/[F]ull/[C]oauthors/[S]kip`, silently doing nothing
when no interactive terminal is available. Skipping leaves the key
unset, which simply means there's no repo-wide default — each
contributor's own migration 001 choice (or the hardcoded `empty`
fallback) still applies.

Safe to re-run — repo-wide, committed state (`applies_to: "repo"`), so
re-running only matters if you want to change the shared default later.
