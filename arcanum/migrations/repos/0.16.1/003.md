# Migration 003 (next) — set your account-wide default squash-merge body mode

Sets the `git.merge_body_mode` key on the global, cross-project config
file (`${CLAUDE_CONFIG_DIR:-$HOME/.claude}/arcanum-config.json`, see
[the global config guide](../../../../docs/guides/arcanum-global-config.md)),
the outermost tier of the config chain — the fallback every repo you
touch uses when neither its own local per-clone setting (migration 001)
nor its repo-wide setting (migration 002) is set.

Same three modes as migrations 001/002 — `empty` (today's behavior),
`full` (GitHub/`gh`'s own default squash body), or `coauthors` (a
deduped `Co-authored-by:` block from the PR's commits). See 001.md for
the full explanation of each mode.

Applies machine/account-wide, across every repo the active Claude Code
account/profile touches — not committed to any repo. Same interactive
shape as migrations 001/002: `[E]mpty/[F]ull/[C]oauthors/[S]kip`,
silently doing nothing when no interactive terminal is available.
Skipping leaves the key unset, which simply means there's no
account-wide default — each repo's own local/repo-tier choice (or the
hardcoded `empty` fallback) still applies. If the global config
location can't be resolved (no `$HOME`/`$CLAUDE_CONFIG_DIR`), the
underlying write degrades silently on its own — no extra handling
needed here.

Safe to re-run — global, cross-project state (`applies_to: "global"`),
so re-running only matters if you want to change your account-wide
default later.
