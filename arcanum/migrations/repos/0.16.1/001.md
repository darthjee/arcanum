# Migration 001 (next) — set your personal squash-merge body mode

Sets the `git.merge_body_mode` key on your local, per-clone
`.claude/state/arcanum-config.json`, used by `cmd_pr_merge`
(`auto-fix-all/scripts/github.sh`, via `arcanum/_lib/merge_body.sh`) to
decide what body to give the commit created when auto-fix-all
squash-merges a PR:

- `empty` — no body (today's behavior, unchanged if you skip this).
- `full` — let GitHub/`gh` pick its own default squash body.
- `coauthors` — a deduped `Co-authored-by:` block built from the PR's
  commits (excluding the merging identity itself, and excluding the
  AI model's own line too when `git.omit_model_coauthor` is set).

Unlike `git.email`, there is no derivable default to guess here (no
existing git config value to split/reuse) — this is a pure preference
choice among the three modes. When an interactive terminal is
available, you're prompted `[E]mpty/[F]ull/[C]oauthors/[S]kip`.
Skipping leaves the key unset, which simply means `merge_body_mode()`'s
own hardcoded default (`empty`) applies at use-time — identical to
today's behavior. When no interactive terminal is available (e.g.
automated/CI-style runs), the migration silently does nothing (there is
no guess to fall back to, unlike `git.email`'s scripts).

Safe to re-run — local, per-clone state (`applies_to: "local"`), so it
re-prompts on every clone/run.
