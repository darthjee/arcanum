# Migration 001 — seed the namespaced arcanum config files

Copies the content of the legacy `.claude/configuration/auto-fix-all.json`
into `.claude/configuration/arcanum-repo-config.json`, under the
`auto-fix-all` namespace key — and does the same for the legacy
`.claude/state/auto-fix-all-config.json` into
`.claude/state/arcanum-config.json`. After this runs, the repo stops
relying on the legacy-file fallback for `auto-fix-all` configuration
(see `docs/guides/arcanum-repo-config.md`).

Safe to re-run: for each file, if the `auto-fix-all` key already exists
in the target, seeding is a no-op. Marked `skippable: true` — the
runtime fallback+warning remains a permanent safety net even if this
migration is skipped or fails, so `auto-fix-all` keeps working either
way.
