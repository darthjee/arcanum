# Migration 001 (next) — seed the shipit-merge permission exemption (local)

Grants a single, narrowly-scoped Bash-permission allowlist entry —
`Bash(auto-fix-all/scripts/wait_ci_and_merge.sh *)` — in this clone's
gitignored `.claude/settings.local.json`, so Claude Code's own
permission classifier stops asking for confirmation before running
that one script.

`wait_ci_and_merge.sh` is the dedicated script `auto-fix-all` calls
*only* on the `shipit`-preapproved merge path (see issue #170): it
waits for CI, then merges the PR internally. The normal, human-review-
approved merge path calls a different, separate Bash invocation
(`scripts/github.sh pr-merge`), which stays unaffected and still hits
the classifier — this migration does not touch it. See
`docs/agents/architecture/issue-tags.md`'s `shipit` paragraph for the
full rationale.

This is local to your own clone only (`applies_to: "local"`) — not
committed, not shared with other contributors. See migration 002 for
the equivalent, committed/shared grant, and 003 for the equivalent
grant across every arcanum-onboarded repo on this machine/account.

Skipping this migration is harmless: `auto-fix-all` still works end to
end, it will just stop at the merge step for `shipit`-preapproved
issues and ask you to confirm, exactly like today. Safe to re-run —
the grant is deduped, not appended twice.
