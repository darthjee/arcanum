# Migration 003 (next) — report a local `ignored_check_patterns` that now overrides the repo value

Warn-only. Reads the repo-local `.claude/state/arcanum-config.json` and, if
`auto-fix-all.ignored_check_patterns` holds a value (anything but `null`),
prints one warning naming the value and the file, and gives the command
that removes it: `arcanum config unset auto-fix-all.ignored_check_patterns --local`.

Why: until #907 this key could only be read from the committed repo config
(`.claude/configuration/arcanum-repo-config.json`), so a value in the local
state file was silently ignored. #907 allows the local tier for it, and the
local tier wins over the repo tier, so such a value now overrides the
repo's committed patterns for this checkout. This migration tells you about
it, in case the value was a leftover you no longer want.

It changes nothing: it never writes or deletes any file. A missing local
file, or one without the key, prints nothing. A file that is not valid JSON
prints a single warning that it could not be read. It always succeeds.

Skippable, and safe to re-run: it only reads.
