# Migration 003 (next) — set the team-wide default per-agent commit email

Sets the `git.email` key on the shared, committed
`.claude/configuration/arcanum-repo-config.json`, as the repo-wide
default every contributor falls back to when they haven't set their own
personal value via migration 002 (`.claude/state/arcanum-config.json`
always takes precedence over this file when both are set).

**Same per-agent *template* rule as migration 002:** the value must
contain the literal substring `{agent}`, substituted with the actual
agent name (`architect`, `backend`, ...) at commit time — never a
single static address. See 002.md for the full explanation and an
example.

**This value gets committed to the repo and is visible to every
contributor** — you'll see an explicit warning to that effect before
being asked to confirm/type/skip. Same interactive shape as migration
002 otherwise: guesses a default from `git config user.email`, offers
`[Y]es/[T]ype/[S]kip` (or `[T]ype/[S]kip` only when there's no guess),
writes the guess silently with no prompt when there's no interactive
terminal available. Skipping leaves the key unset, which simply means
there's no repo-wide default — each contributor's own migration 002
choice (or its own unset-fallback to the AI model's email) still
applies.

Safe to re-run — repo-wide, committed state (`applies_to: "repo"`), so
re-running only matters if you want to change the shared default later.
