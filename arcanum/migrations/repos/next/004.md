# Migration 004 (next) — add the co-author policy line to AGENTS.md

Appends a `## Commit Attribution` section to the repo's `AGENTS.md`, holding
one line that says commit co-author trailers follow arcanum's resolved
`git.omit_model_coauthor` and `git.remove_coauthors` config.

Why: without that line, a commit written by hand follows Claude Code's own
attribution reminder and ignores the arcanum config. The line in `AGENTS.md`
makes the config override that reminder for every commit.

Safe to re-run: if `AGENTS.md` already contains the exact line, nothing is
written. A repo without an `AGENTS.md` is left untouched.

Skippable: yes. Skipping only means hand commits keep following Claude
Code's reminder.
