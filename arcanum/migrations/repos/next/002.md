# Migration 002 (next) — report global values that now take effect

Warn-only. Reads the global config file
(`${CLAUDE_CONFIG_DIR:-$HOME/.claude}/arcanum-config.json`) and, for each of
these keys that holds a value (anything but `null`), prints one warning:

- `git.safe_branch`
- `auto-fix-all.clear_context`
- `auto-fix-all.finish_on_empty_queue`
- `monitor-issues.clear_context`

Each warning names the key, its value and the file, and gives the command
that removes it: `arcanum config unset <key> --global`.

Why: until #907 these keys could not be read from the global tier, so a
value there was silently ignored. #907 allows the global tier for them, so
such a value now applies to every repo that does not set the key locally.
This migration tells you about it, in case the value was a leftover you no
longer want.

It changes nothing: it never writes or deletes any file. A missing global
file, an unresolvable location (no `$HOME` and no `CLAUDE_CONFIG_DIR`) or a
file with none of the keys prints nothing. A file that is not valid JSON
prints a single warning that it could not be read. It always succeeds.

Skippable, and safe to re-run: it only reads.
