# Migration 002 Instructions — Link the Specs Index from AGENTS.md

Add the specs index (`docs/agents/specs.md` and the `docs/agents/specs/`
folder) to the target repo's `AGENTS.md` `## Documentation` section,
mirroring what `/init-claude` now writes for newly initialized repos.

1. Check whether `AGENTS.md` exists at the target repo root. If it does
   not exist, there is nothing to do — mark this entry complete without
   making any changes.

2. Read the canonical text from
   `init-claude/templates/agents-documentation-section.md` in the
   arcanum install — i.e. `../../../../init-claude/templates/agents-documentation-section.md`
   relative to this instructions file. You need two pieces from it:
   - the table row starting with `| [Specs](docs/agents/specs.md) |`;
   - the whole `### Specs (`docs/agents/specs/`)` subsection, from its
     heading up to (not including) the next heading or the end of the
     file.

3. If `AGENTS.md` has no `## Documentation` section, or the section has
   been restructured beyond recognition (so it's unclear where the specs
   index should go), ask the user where — or whether — to add it rather
   than guessing.

4. Add only the piece(s) that are missing:
   - **The row:** add it to the Documentation section's file table, e.g.
     right after the `Issues` row (or at the end of the table if there
     is no `Issues` row). Any existing link to `docs/agents/specs.md`
     anywhere in the section counts as the row being present — do not
     add a second one.
   - **The subsection:** add it after the last existing `###`
     subsection of the Documentation section (e.g. after
     `### Plans (`docs/agents/plans/`)`), before the next `##` heading.
     An existing `### Specs` subsection (any wording) counts as present.

   If both pieces are already present, make no changes.

5. If the Documentation section is shaped differently from the template
   (e.g. a bullet list instead of a table, or prose), follow its
   existing format: express the specs index entry in the same style
   (a bullet, a sentence) rather than forcing a table row in.

6. Never touch anything else in `AGENTS.md`. Save the file.

This migration only ever touches `AGENTS.md`. It never creates or edits
`docs/agents/specs.md` or `docs/agents/specs/` — migration 001 handles
those.
