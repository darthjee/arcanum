# Migration 001 (next) — create the new commit-message template

Copies arcanum's own `.github/commit_message_template-2.0.md` into this
repo's `.github/` folder, if it isn't already there — same create-if-
absent behavior as `init-claude`'s `setup_templates.sh`, and it never
touches the existing `.github/commit_message_template.md`.

This file's mere *presence* is what switches `commit_change.sh`,
`commit_issue.sh`, and `commit_plan.sh` onto the new commit-message
shape (a distinct, independently-configurable email on the "agent"
`Co-Authored-By` line, instead of always reusing the AI model's own
email) — its content is never parsed at runtime, it only documents the
shape for humans. See docs/agents/issues/156-improve-commit-template.md
for the full design.

Skipping this migration is harmless and simply keeps this repo on the
old commit-message shape until it's applied later — nothing else
depends on it. Safe to re-run: re-running is a no-op once the file
exists (`applies_to: "repo"`, so this is committed and shared, not
per-clone).
