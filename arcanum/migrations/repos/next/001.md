# Migration 001 (next) — add the specs index scaffold

Creates `docs/agents/specs.md`, copied byte-for-byte from arcanum's
canonical `init-claude/templates/specs.md`, and an empty
`docs/agents/specs/.gitkeep` when `docs/agents/specs/` is missing or
empty — the same specs scaffold `/init-claude` gives newly initialized
repositories.

Existing files are never overwritten: an existing `docs/agents/specs.md`
(of any kind) is left untouched, and no `.gitkeep` is added to a
`docs/agents/specs/` that already has content. If `docs/agents/specs`
exists but is not a directory, a warning is printed and the `.gitkeep`
is skipped.

Safe to re-run: once both are in place, re-running is a no-op
(`applies_to: "repo"`, so the result is committed and shared, not
per-clone). Skipping it is harmless for repos that don't use
`docs/agents/`.
