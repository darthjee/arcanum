# Migration 001 (next) — announce the opt-in engine.mode config key (local)

Prints a one-time, advisory notice about the new `engine.mode` config
key (see `arcanum/_lib/engine_dispatch.sh` and
`docs/agents/architecture/script-engine.md`), which lets arcanum
dispatch some shell entrypoints to a native (Node.js) implementation
instead.

This is experimental and opt-in: enabling `engine.mode=native` today
only activates a native path for `resolve-and-fetch` (issue #193) —
every other entrypoint still silently falls back to the shell
implementation, per `engine_dispatch.sh`'s fallback rule.

Makes no file changes — it only prints where to set the key (local,
repo, or global config tier) and what values it accepts (`shell`
default, `native`, `docker`). Trivially idempotent and safe to re-run;
skipping it is harmless, since nothing here is required for arcanum to
keep working as before.
