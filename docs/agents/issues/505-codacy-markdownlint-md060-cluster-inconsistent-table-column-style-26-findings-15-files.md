# Issue: Codacy: markdownlint MD060 cluster — inconsistent table column style (26 findings, 15 files)

## Description

Codacy's markdownlint flags 26 findings (15 files) for inconsistent GitHub-Flavored-Markdown table column/pipe styling (mixing `aligned`, `compact`, and `tight` pipe formatting within or across tables).

**Source:** Codacy quality issues, category CodeStyle, severity **Info**, tool markdownlint (`markdownlint_MD060` — table-column-style).

## Affected files (count in parentheses)

`.claude/agents/architect.md` (2), `AGENTS.md` (2), `README.md` (2), `auto-fix-issue/steps/run.md` (1), `docs/agents/architecture.md` (1), `docs/agents/architecture/agent-roster-and-delegation.md` (1), `docs/agents/architecture/dispatch-permissions.md` (1), `docs/agents/architecture/entrypoint-migration-status.md` (1), `docs/agents/architecture/shared-state-and-configuration.md` (1), `docs/agents/folder-structure.md` (1), `docs/agents/tag-mutations.md` (1), `docs/guides/arcanum-repo-config.md` (2), `init-claude/SKILL.md` (8), `init-claude/sample-contributing.md` (1), `init-claude/setup_auto_fix_all_settings.md` (1).

Note: `docs/agents/tag-mutations.md` and `docs/agents/architecture/entrypoint-migration-status.md` are marked `AUTO-GENERATED, DO NOT EDIT BY HAND` (per `AGENTS.md`'s Boundaries section) — their formatting should be fixed via the `scripts/generate_*.sh` that produces them, not by hand.

A sampling of the 15 files confirms the repo's tables are overwhelmingly `compact` style already (single space around cell content, delimiter row not padded to column width — e.g. `AGENTS.md`, `README.md`, `docs/agents/folder-structure.md`, `auto-fix-issue/steps/run.md`, `docs/agents/architecture.md`, `docs/agents/architecture/agent-roster-and-delegation.md`, `docs/agents/architecture/dispatch-permissions.md`, `init-claude/sample-contributing.md`, `init-claude/setup_auto_fix_all_settings.md`, `docs/agents/architecture/shared-state-and-configuration.md`, `docs/guides/arcanum-repo-config.md`). Only `init-claude/SKILL.md`'s scenario table uses fully space-padded `aligned` style, making it the outlier to reformat.

## Expected Behavior

- All tables in the listed files use the `compact` pipe style (single space around cell content; delimiter row need not be padded to column width) — matching the style the large majority of existing tables already use.
- `.markdownlint.json` pins `"MD060": { "style": "compact" }`, mirroring how MD013 was pinned for Markdown in #492/#493.
- The two autogenerated docs (`docs/agents/tag-mutations.md`, `docs/agents/architecture/entrypoint-migration-status.md`) are fixed via their generator scripts, not by hand-editing.
- Re-running markdownlint/Codacy shows zero MD060 findings among these 15 files.

## Solution

1. Add `"MD060": { "style": "compact" }` to `.markdownlint.json`, pinning the repo's dominant existing style (mirroring how MD013 was pinned in #492/#493).
2. Reformat tables in the 13 hand-written files to `compact` style — most are auto-fixable by markdownlint's `--fix`; `init-claude/SKILL.md`'s aligned scenario table needs manual de-padding.
3. Regenerate the 2 autogenerated docs via their `scripts/generate_*.sh` scripts rather than hand-editing.
4. Confirm zero MD060 findings remain via Codacy/markdownlint re-run.
