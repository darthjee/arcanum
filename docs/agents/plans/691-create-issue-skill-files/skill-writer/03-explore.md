# steps/explore.md

New `arcanum-create-issue/steps/explore.md`, the same light pass as `enhance-issue/steps/explore.md`, run on the draft `FILE` (the initial idea, or a resumed draft) instead of a fetched issue:

1. Read `FILE` for general understanding.
2. If the idea plausibly references existing code, files or behavior, do a quick targeted read yourself — no specialist agents by default.
3. Skip entirely when no code context would change the conversation.

Then proceed to [dialogue.md](dialogue.md).
