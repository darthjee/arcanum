# Scaffold the package

Create the package files so `yarn install`, `yarn lint` and `yarn test` work inside `shared/`.

- `shared/package.json`:
  - `"name": "@arcanum/shared"`, `"version": "0.1.0"`, `"private": true`, `"type": "module"`, a one-line `description`, `"engines": { "node": ">=22.13.0" }`;
  - `scripts`: `"test": "c8 jasmine"`, `"lint": "eslint ."`;
  - `devDependencies`, pinned exactly like `cli/package.json`: `@eslint/js` `10.0.1`, `c8` `12.0.0`, `eslint` `10.8.1`, `eslint-plugin-jsdoc` `63.3.3`, `globals` `17.11.0`, `jasmine` `7.0.0`;
  - **no** `dependencies`, `optionalDependencies` or `peerDependencies` keys;
  - `c8`: `reporter` `["text", "lcov"]`, `exclude` `["spec/**", "eslint.config.mjs"]`, `check-coverage: true`, thresholds as placeholders (`50`) until step 06 sets them.
- `shared/spec/support/jasmine.json`: `spec_dir` `spec`, `spec_files` `["**/*_spec.js"]`, **no** `helpers` (so `ARCANUM_STRICT_CONFIG_KEYS` is never set by the runner), `env` `{ stopSpecOnExpectationFailure: false, random: true }`.
- `shared/yarn.lock`: generated by `yarn install` in `shared/`.
- Root `.gitignore`: add `shared/node_modules/` and `shared/coverage/`, next to the `core/` and `cli/` lines.
- `shared/README.md`: what `shared/` is (code consumed by both `core/` and `cli/`; first content is the config surface), its layout, the import boundary (`node:` built-ins and files under `shared/lib/` only; no dynamic `import()`; `core/` and `cli/` never import `shared/spec/`), zero runtime dependencies, how to run lint and specs, a note on the copy window and drift rule until #824, and a link to `docs/agents/specs/shared-lib.md`.
